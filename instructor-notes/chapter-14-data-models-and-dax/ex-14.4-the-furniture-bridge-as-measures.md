## Purpose and learning outcomes

Chapter 6's bridge explained the fall in Furniture's margin for one pair of quarters, on a worksheet. The controller wants it in the model, readable for other quarters and item groups, wherever the quarter before has sales. The exercise puts the chapter's three ideas together: variables, a shifted filter context with DATEADD, and ratios computed on totals. It ends with a check measure that must be zero, which turns a bridge into a test of itself. The analytics type is diagnostic: the bridge says which effect explains the change.

Students can:

- shift the filter context back one quarter with DATEADD (Requirement 1);
- write the four effects with variables, following Tutorial 6.3's cells (Requirement 2);
- add a check measure and say why no cost effect is needed (Requirement 3);
- read a bridge by quarter and reproduce Chapter 6's (Requirement 4);
- say which effect explains a quarter, for two item groups (Requirements 5 and 6).

**Competencies practiced.** CPA Evolution BAR M5 (cost accounting and variance analysis) and BAR M10 (advanced data analytics: data models and joins, dashboards); IMA Strategy, Planning and Performance (strategic cost management) and Data Analytics and Insights (data analysis); IFAC IES 2 (b) (management accounting) and IES 2 (i) (using information and communications technologies to analyze data); AACSB A5 part 5.1, with part 5.3 (learning to learn and continuous technological adaptability) when the instructor adds an independent-learning task.

## Step-by-step solution

### Requirement (1): Units and Margin PQ

**Step 1. Add the two measures.**

a. Select **Key Measures** and choose **Modeling > New measure** for each.
b. Type `Ex 14.4` in **Display folder** in **Model view**.

```dax
Units = SUM ( SalesInvoiceLine[Quantity] )
Margin PQ = CALCULATE ( [Gross Margin], DATEADD ( 'Date'[Date], -1, QUARTER ) )
```

**Check:** both measures sit in the folder. DATEADD shifts the dates in the filter context back one quarter, so for any quarter the measure reads the quarter before. For 2026-Q1 the shift reaches the fourth quarter of 2025, and the Checks tab computes it: that Margin PQ is $1,895,399.20. The first quarter of the data, 2024-Q1, has no quarter before it, so its Margin PQ is blank.

### Requirement (2): The four effects

**Step 2. Write the Volume Effect from the exercise.** Add the measure as printed. It values the change in units at the prior quarter's margin per unit.

```dax
Volume Effect =
VAR PriorQuarter = DATEADD ( 'Date'[Date], -1, QUARTER )
VAR UnitsPQ = CALCULATE ( [Units], PriorQuarter )
VAR MarginPerUnitPQ =
    CALCULATE ( DIVIDE ( [Gross Margin], [Units] ), PriorQuarter )
RETURN
    ( [Units] - UnitsPQ ) * MarginPerUnitPQ
```

**Step 3. Write the other three in the same way.** Each takes a per-unit amount in the current quarter and in the prior one, as the exercise's formulas state, and multiplies by the current units.

```dax
Mix Effect =
VAR PriorQuarter = DATEADD ( 'Date'[Date], -1, QUARTER )
VAR ListMarginPerUnit = DIVIDE ( [List Amount] - [Standard Cost], [Units] )
VAR ListMarginPerUnitPQ =
    CALCULATE ( DIVIDE ( [List Amount] - [Standard Cost], [Units] ), PriorQuarter )
RETURN
    [Units] * ( ListMarginPerUnit - ListMarginPerUnitPQ )
```

```dax
Price List Effect =
VAR PriorQuarter = DATEADD ( 'Date'[Date], -1, QUARTER )
VAR ReductionPerUnit = DIVIDE ( [List Amount] - [Revenue] - [Discounts], [Units] )
VAR ReductionPerUnitPQ =
    CALCULATE ( DIVIDE ( [List Amount] - [Revenue] - [Discounts], [Units] ), PriorQuarter )
RETURN
    - [Units] * ( ReductionPerUnit - ReductionPerUnitPQ )
```

```dax
Promotion Effect =
VAR PriorQuarter = DATEADD ( 'Date'[Date], -1, QUARTER )
VAR DiscountPerUnit = DIVIDE ( [Discounts], [Units] )
VAR DiscountPerUnitPQ =
    CALCULATE ( DIVIDE ( [Discounts], [Units] ), PriorQuarter )
RETURN
    - [Units] * ( DiscountPerUnit - DiscountPerUnitPQ )
```

**Check:** four measures in the folder. The Mix Effect uses margin per unit at list price, the Price List Effect the reduction from list to the invoiced price before the discounts, and the Promotion Effect the discount per unit. The last two carry a minus sign, because a larger reduction lowers the margin.

### Requirement (3): Bridge Check

**Step 4. Add the check measure.**

```dax
Bridge Check =
[Margin PQ] + [Volume Effect] + [Mix Effect] + [Price List Effect]
    + [Promotion Effect] - [Gross Margin]
```

**Check:** the measure is Margin PQ plus the four effects less Gross Margin, so it is zero when the effects explain the whole change. No cost effect is needed: each item has one standard cost, so a unit's cost changes only through the mix of items, and the mix effect already holds it. **Watch for:** a check that is not zero. Two wrong versions are common.

- A **Price List Effect** that does not take the discounts out of the reduction. The Promotion Effect then counts them again, and Bridge Check equals the promotion effect itself: -$120,687.02 in Q4, and the price-list effect reads -$119,613.77 in place of +$1,073.25.
- A **Volume Effect** at the current quarter's margin per unit. Bridge Check is then the change in units times the change in margin per unit, -$533.18 in Q4: small, and not zero.

### Requirement (4): The matrix

**Step 5. Build the bridge by quarter.**

a. Add a page named `Ex 14.4` and select **Matrix**.
b. Drag YearQuarter from **Date** into **Rows**, and Margin PQ, Volume Effect, Mix Effect, Price List Effect, Promotion Effect, Gross Margin and Bridge Check into **Values**.
c. In **Filters on this visual**, keep the year 2026 and the item group Furniture.

**Check:** the page titled "Furniture margin bridge by quarter, fiscal 2026":

| Quarter | Margin PQ | Volume | Mix | Price lists | Promotions | Margin |
|---|---:|---:|---:|---:|---:|---:|
| Q1 | $1,895,399.20 | -$80,923.53 | -$14,812.65 | -$759.08 | +$75,710.81 | $1,874,614.74 |
| Q2 | $1,874,614.74 | +$106,551.62 | +$19,161.18 | -$4,820.34 | -$10,344.08 | $1,985,163.11 |
| Q3 | $1,985,163.11 | -$100,923.52 | -$10,716.35 | +$11,707.89 | -$74,974.04 | $1,810,257.09 |
| Q4 | $1,810,257.09 | +$7,885.63 | -$3,317.93 | +$1,073.25 | -$120,687.02 | $1,695,211.02 |

A sign shows the direction of each effect. The Q4 row reproduces Chapter 6's bridge, and Bridge Check is zero in every row. A zero tests the arithmetic of the bridge, not whether the two quarters can be compared. In 2024-Q1, which has no quarter before it, Bridge Check is zero too, because the mix, price-list and promotion effects then add up to the whole margin. Read a bridge only for a quarter with sales in it and in the quarter before. The Total row compares the whole year with its dates moved back one quarter, so its effects are not the sum of the rows.

### Requirement (5): The third quarter

**Step 6. Read the Q3 row.** The margin falls from $1,985,163.11 to $1,810,257.09, $174,906.02. Two effects explain it: fewer units than in Q2, a volume effect of -$100,923.52, and the first month of promotion 8, September, with a promotion effect of -$74,974.04. The fourth quarter differs: volume, mix and price lists are small, and the promotion effect of -$120,687.02 is larger than the whole decline of $115,046.07. The effects split the margin at standard cost in the bridge's order, so they say where the margin went, not what the promotion did to demand, which needs evidence such as Chapter 7's comparison of the units sold with the break-even lift.

![How the four effects add up from one quarter's margin to the next, the picture to draw on the board before students write the measures.](../figures/chapter-14-data-models-and-dax/IF-14-4-B.pdf)

### Requirement (6): Lighting

**Step 7. Change the item group filter to Lighting.**

a. In **Filters on this visual**, change Furniture to Lighting.
b. Read the Q4 row.

**Check:** the page titled "Lighting margin bridge by quarter, fiscal 2026" shows the second matrix of the model answer. Lighting's margin moves from $683,521.69 to $657,275.48. The volume effect, -$33,743.58, explains most of it: a volume decline, not a price effect. The mix is +$9,253.87, the price lists +$4,540.45 and the promotions -$6,296.95.

## What a strong answer says

- **(3)** One standard cost for each item, so cost per unit moves only with the mix, and a cost effect would be zero.
- **(5)** Volume and the first month of the promotion together for Q3; for Q4, a promotion effect larger than the decline, with the others small.
- **(6)** Lighting's change is mostly volume, so the first question is why its units fell, not what to do about its prices.

A strong answer names the effect and gives its size against the decline. A weak one lists the effects without ranking them.

## Common mistakes and how to respond

- **Discounts counted twice.** *Symptom:* Bridge Check of -$120,687.02 in Q4. *Response:* ask which measure already holds the discounts.
- **Volume at the wrong margin.** *Symptom:* a Bridge Check of -$533.18. *Response:* ask which quarter's margin per unit the volume step uses.
- **A cost effect added.** *Symptom:* a fifth measure that reads zero. *Response:* ask how many standard costs an item has.
- **A sign dropped.** *Symptom:* a promotion effect with the wrong sign. *Response:* ask what a larger discount does to the margin.
- **Reading Q4 as volume.** *Symptom:* "fewer units". *Response:* ask which effect exceeds the decline.
- **Lighting read as price.** *Symptom:* a price remedy for Lighting. *Response:* ask which effect is largest there.
