This register lists every data fact the book relies on, as verified against the dataset of the 2026 edition:

- Charles River dataset v2026.1, fiscal 2024–2026;
- `CharlesRiver.sqlite` SHA-256 `de861968e07412d71032b6ed6a0fb8eb9825cf6911886b1597c4a628a914474c`, the same file as release v1.0.0-rc1 after its assets were re-uploaded on 2026-05-09.

- **Physical facts about `datasets/CharlesRiver.sqlite`:**
  - every table has a single-column INTEGER surrogate primary key, and there are unique indexes on document numbers (not on PurchaseInvoice.InvoiceNumber);
  - **no foreign keys are declared** (`foreign_keys` = 0): relationships are logical and must be tested;
  - there are only three declared types. Dates are TEXT `YYYY-MM-DD`, money is REAL, and flags are INTEGER 0/1;
  - GLEntry has no JournalEntryID. GLEntry.AccountID is the Account table's surrogate key, not the account number (AccountID 42 is account 4010), so tutorials must name both. VoucherNumber holds the source document's number (for example SI-2025-007947, or the JournalEntry EntryNumber);
  - PayrollSummary is the one SourceDocumentType that is not a table: its SourceDocumentID is a composite code (1,000,000 + PayrollPeriodID × 1000 + CostCenterID);
  - fiscal year 2027 contains only DisbursementPayment rows (supplier payments for prior-year invoices). Year-end close journal entries (EntryType "Year-End Close …", dated 12-31) debit revenue and credit COGS, so any quarterly revenue or margin analysis must exclude them;
  - payroll posts as PayrollSummary, PayrollPayment and PayrollLiabilityRemittance, and 6 PayrollPayment GL rows are trace orphans;
  - the traced sale is invoice SI-2025-007947 (GLEntry 126312, Cr 4010 $688.42, line 10645): Figure 1.6 shows its revenue posting and Tutorial 3.2 traces it in full;
