# Exercise 14.4: The Furniture Bridge as Measures

{{ header() }}

## Purpose and learning outcomes

Chapter 6's bridge explained the fall in Furniture's margin for one pair of quarters, on a worksheet. The controller wants it in the model, readable for any quarter and any item group. The exercise puts the chapter's three ideas together: variables, a shifted filter context with DATEADD, and ratios computed on totals. It ends with a check measure that must be zero, which turns a bridge into a test of itself. The analytics type is diagnostic: the bridge says which effect explains the change.

Students can:

- shift the filter context back one quarter with DATEADD (Requirement 1);
- write the four effects with variables, following Tutorial 6.3's cells (Requirement 2);
- add a check measure and say why no cost effect is needed (Requirement 3);
- read a bridge by quarter and reproduce Chapter 6's (Requirement 4);
- say which effect explains a quarter, for two item groups (Requirements 5 and 6).

**Competencies practiced.** CPA Evolution BAR M5 (cost accounting and variance analysis) and BAR M10 (advanced data analytics: data models and joins, dashboards); IMA Strategy, Planning and Performance (strategic cost management) and Data Analytics and Insights (data analysis); IFAC IES 2 (b) (management accounting) and IES 2 (i) (using information and communications technologies to analyze data); AACSB A5 part 5.1, with part 5.3 (learning to learn and continuous technological adaptability) when the instructor adds an independent-learning task.

### Requirement (3): Bridge Check

**Step 4. Add the check measure.**

```dax jinja
{{ g.m_check }}
```

**Check:** the measure is Margin PQ plus the four effects less Gross Margin, so it is zero when the effects explain the whole change. No cost effect is needed: each item has one standard cost, so a unit's cost changes only through the mix of items, and the mix effect already holds it. **Watch for:** a check that is not zero. Two wrong versions are common.

- A **Price List Effect** that does not take the discounts out of the reduction. The Promotion Effect then counts them again, and Bridge Check equals the promotion effect itself: {{ sm(g.wrong[3].check) }} in {{ q4.label }}, and the price-list effect reads {{ sm(g.wrong[3].lists) }} in place of {{ sm(q4.lists) }}.
- A **Volume Effect** at the current quarter's margin per unit. Bridge Check is then the change in units times the change in margin per unit, {{ sm(g.wrong[3].volume_check) }} in {{ q4.label }}: small, and not zero.

## What a strong answer says

- **(3)** One standard cost for each item, so cost per unit moves only with the mix, and a cost effect would be zero.
- **(5)** Volume and the first month of the promotion together for {{ q3.label }}; for {{ q4.label }}, a promotion effect larger than the decline, with the others small.
- **(6)** Lighting's change is a volume decline, so a price remedy would miss it.

A strong answer names the effect and gives its size against the decline. A weak one lists the effects without ranking them.

## Common mistakes and how to respond

- **Discounts counted twice.** *Symptom:* Bridge Check of {{ sm(g.wrong[3].check) }} in {{ q4.label }}. *Response:* ask which measure already holds the discounts.
- **Volume at the wrong margin.** *Symptom:* a Bridge Check of {{ sm(g.wrong[3].volume_check) }}. *Response:* ask which quarter's margin per unit the volume step uses.
- **A cost effect added.** *Symptom:* a fifth measure that reads zero. *Response:* ask how many standard costs an item has.
- **A sign dropped.** *Symptom:* a promotion effect with the wrong sign. *Response:* ask what a larger discount does to the margin.
- **Reading {{ q4.label }} as volume.** *Symptom:* "fewer units". *Response:* ask which effect exceeds the decline.
- **Lighting read as price.** *Symptom:* a price remedy for Lighting. *Response:* ask which effect is largest there.
