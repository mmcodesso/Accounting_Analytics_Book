*Accounting Analytics: An Integrated Approach* is an open educational resource. It helps accounting students develop
analytical skills through accounting examples and applications using Excel, SQL, and Power BI.

**[Read the book online](https://aa.accountinganalyticshub.com/)**

## Downloads

This repository holds the downloadable files of the book, one release for each revision of the first edition:

- the book as a PDF, an EPUB, and a DOCX,
- the PowerPoint slides of every chapter and comprehensive case, and
- the start files that let you begin any tutorial of Parts II to IV where the previous one ended.

**[Newest revision](https://github.com/mmcodesso/Accounting_Analytics_Book/releases/latest)** ·
[All revisions](https://github.com/mmcodesso/Accounting_Analytics_Book/releases)

The [book's website](https://aa.accountinganalyticshub.com/) always shows the newest text, and its
[Downloads page](https://aa.accountinganalyticshub.com/front-matter/downloads.html) explains how to use each file.
The book itself is written in a private repository, so this one holds releases only.

## The Charles River dataset

Every chapter works with the Charles River Accounting Dataset, the records of one fictional company. Its files,
documentation, and updates are on the [dataset website](https://charlesriver.accountinganalyticshub.com/) and in the
[dataset repository](https://github.com/mmcodesso/CharlesRiver_Database).
